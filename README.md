# Aurora Pulso

Ferramenta leve de linha de comando para monitorar filas de tarefas e gerar relatórios diários em JSON.

## Funcionalidades

- Rastreamento de latência em tempo real
- Exportação automática para CSV e JSON
- Suporte a webhooks configuráveis

## Instalação

```bash
npm install -g aurora-pulse
```

## Uso rápido

```bash
aurora-pulse watch --queue emails --interval 30
```
